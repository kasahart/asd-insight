# 大容量音声の軽量保存と再開（Issue #3）

軽量保存は、元CSV・音声の本体をブラウザー内へコピーせず、解析設定と調査状態を保存する方式です。全量保存は従来どおり利用できます。容量不足で自動的に方式を切り替えません。

## 選択と保存する内容

CSV・TSVの読み込み画面で、保存する内容を選びます。

| 方式 | 保存・バックアップに含むもの | 再開時に必要なもの |
|---|---|---|
| 全量保存 | 元CSV、展開済み行、WAV本体、解析設定、調査状態 | 保存済み分析またはバックアップ |
| 軽量保存 | CSVの名前・列構成・行数・サイズ・SHA-256、音声の相対パス・ファイル名・サイズ・更新日時、解析設定、調査状態 | 同じ内容の元CSVと、試聴したい音声 |

調査状態には既存の保存対象である評価列、群分け、絞り込み、探索しきい値、メモ、手動除外と来歴、一覧・表示設定などを含みます。軽量保存はCSV行やWAVのバイト列を含みません。派生した階層列も、保存した相対パスから再構築します。元データを書き換えません。

WAVの取り込み前確認には選択件数・音声本体の総容量・全量保存の容量条件を表示します。全量保存で保存できない場合、保存エラーまたは保存管理画面の「調査状態を軽量保存にコピー」から、現在の未保存の調査も別の分析として保存できます。既存の全量保存は保持します。保存作成中に追加編集された場合は元画面の編集を残し、追加編集が保存されたとは表示しません。

## 再開する手順

1. 「保存した分析」の軽量保存を開くか、軽量保存のバックアップを取り込みます。
2. 「元CSVを選んで再開」で元のCSV・TSVを選びます。サイズ、SHA-256、行数、列順が一致した場合だけ再開します。ファイル名や置き場所は変更できます。CSV内容が違う場合は再開せず、保存済みの調査と表示中の調査を保持します。変更したCSVは新しい分析として開始してください。
3. CSVの集計、階層条件、メモ・除外状態を復元します。音声が未選択でも分析できます。原音対応件数と未選択音声数を表示し、保存した階層所属は音声欠落で消しません。
4. 同じ階層の音声フォルダを選び直し、取り込み前の照合を確認して追加します。部分的なフォルダでも、見つかった音声を追加して、残りは未選択のまま続けられます。

音声を再選択するときは、保存した相対パスとサイズ・更新日時を照合します。既存参照と同名で異なるパス、サイズ・更新日時が変わった音声は、保存した調査に自動で置き換えません。フォルダの移動では、選択するルートからの相対階層を維持してください。未選択音声の参照は、その後の設定保存やコピーでも保持されます。

**音声の内容ハッシュは計算しません。** GB規模の音声全量を保存のたびに読み直すことを避けるためです。同じ相対パス・サイズ・更新日時で内容だけが変わった音声は検出できません。この照合は完全な内容一致の保証ではなく、画面でも明示します。変更された音声を使用する場合は新しい分析として開始してください。

## 保存領域と容量

永続モードでは、軽量保存の設定・調査状態・照合情報を同じブラウザープロファイルのIndexedDBに保存します。音声やCSV本体をOPFSへ書き込みません。一時モードは従来どおり明示的な選択であり、タブを閉じると失われます。

ブラウザーデータを消去すると軽量保存も失われます。バックアップを保管し、消去後はバックアップを開いて元CSV・必要な音声を再選択してください。軽量バックアップは入力本体のバックアップではありません。元データは別途保管が必要です。

件数制限はありません。既存の保存上限である1分析128 MiB、全体256 MiB（配信設定で縮小可能）は、軽量保存では設定・調査状態・照合情報の容量に適用します。調査状態2 MiB、metadata 48 MiB、CSVの読み込み20 MiB・128列などの制約も維持します。WAVの保存総容量は軽量保存の容量に加算しませんが、個別音声のデコード・表示には既存のランタイムと端末性能による制約があります。

全量バックアップは従来のversion 1を維持します。軽量バックアップはversion 2です。現在のアプリは両形式を読みます。旧アプリはversion 2を読み込めません。未知の版、音声本体が混入した軽量形式、重複した参照は拒否し、既存分析を変更しません。

- `tests/production/reference-storage.test.mjs`: GB規模の音声を模したメタデータと読み込み禁止Fileによる、音声バイトの未読・OPFS未書込、永続保存と再開、欠落音声の階層保持、CSV内容変更拒否、音声変更拒否、全量保存失敗からのコピー、100,001件の参照による保存・バックアップ復元、容量超過時の既存分析保持。
- `tests/e2e/reference-sessions.spec.ts`: 合成CSVと小さな実PCM WAVを使い、ブラウザーUIで軽量保存、階層群分け、メモ・除外、reload、異なるCSVの拒否、同一CSVの再選択、変更音声の拒否、部分音声の再対応づけ、軽量バックアップ復元を確認。

GBの実音声本体を全件読む性能試験ではありません。件数が多い場合のフォルダ走査・評価・metadata照合は別途時間を要します。
